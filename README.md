# Expense-Tracker-App
A console-based Java Personal Expense Tracker that lets users add, view, delete, and categorize expenses, manage monthly and category budgets, store data in a SQLite database, generate reports using multithreading, and export data to files with custom exception handling.

## What this project does

- Add new expenses with description, amount, category, and payment method  
- View all saved expenses  
- Filter expenses by category  
- Show total spending and category-wise summary  
- Warn users when a budget limit is exceeded  
- Save expenses in a local SQLite database  
- Export expenses to a CSV file  
- Generate text reports  
- Keep a small history of operations  

## Technologies used

- Java (Core Java concepts like OOP and Exception Handling)
- SQLite with JDBC
- File handling
- Multithreading
- Java Collections

## How to run the project

1. Install JDK (8 or higher) on your system  
2. Make sure the SQLite JDBC driver is added to your project  
3. Open terminal or command prompt in the project folder  
4. Compile the code:
   ```bash
   javac ExpenseTrackerApp.java
